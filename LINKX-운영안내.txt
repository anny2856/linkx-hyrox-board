# LINKX HYROX 선수단

공개 관람 + ChatGPT 인증 관리자 전용 편집 웹앱. 사용자가 제공한 LINKX 회원 출전 27개를 반영했습니다. 연도는 현재 날짜 기준 2026년, 시간은 KST로 적용했습니다. 모든 초기 상태는 대기입니다.

## 실행과 검증

Node.js 24 이상. 외부 패키지 설치 불필요.

```
npm test
npm run dev
```

로컬 http://localhost:4173 은 명단 조회용이며, 데이터는 메모리에 있습니다. 로컬 서버는 사용자 헤더를 전달하지 말고 외부에 공개하지 마세요. 실제 인증은 Sites의 신뢰된 인증 프록시를 통해서만 사용합니다.

## 운영 구성

- Worker: `worker/app.js`, 화면: `web/index.html`, 빌드: `node build.mjs`.
- `.openai/hosting.json`: 기존 project_id 유지, `d1: "DB"`, R2 미사용.
- D1 스키마: `drizzle/0000_dashboard.sql`, journal 포함. 배포 시 적용. 스키마 마이그레이션에서 샘플 삽입을 하지 않습니다.
- 런타임 `ADMIN_EMAILS`: 쉼표로 구분한 ChatGPT 계정 이메일. Sites 비밀 환경변수로 설정. 변경 후 재배포 필요. 비어 있으면 모든 편집 거부.
- 공개 접근 `public`. 조회 API 인증 불필요. 쓰기 API는 인증 ID + 이메일 허용 목록 + Origin 검증.
- 플랫폼이 인증한 `oai-authenticated-user-id/email`만 신뢰합니다. 원본 Worker를 인증 프록시 밖에 노출하지 마세요.
- 로그인 `/signin-with-chatgpt?return_to=%2F%3Fadmin%3D1`, 로그아웃 `/signout-with-chatgpt?return_to=%2F`는 플랫폼 제공 경로입니다.
- 상태는 서버 D1에 저장합니다. SSE로 약 2초 간격 변경 감지/전송, 약 50초마다 스트림 재연결, 실패 시 10초 간격 조회로 복구합니다. 이는 수동 경기 상태이며 공식 계측 기록이 아닙니다.
- 수정은 버전 번호가 일치해야 적용됩니다. 충돌 시 409를 반환하여 오래된 변경의 덮어쓰기를 방지합니다. 감사 테이블에는 작업자·대상·시각이 저장됩니다.
- DB 초기화 전에는 전달받은 명단 미리보기를 제공합니다. 관리자가 '명단 저장 및 관리 시작'을 누르면 출전 27개를 저장합니다. 이후 모두 삭제해도 재생성되지 않습니다.

## 관리자 사용 순서

1. 관리자 로그인 → 등록한 ChatGPT 계정으로 로그인.
2. '명단 저장 및 관리 시작' 클릭.
3. 선수/일정 추가 또는 기존 항목 편집. 복식·릴레이도 LINKX 회원 이름만 입력합니다. 한 명만 적힌 출전도 그대로 표시하며 미확정으로 취급하지 않습니다. 동일 선수가 여러 종목에 출전하면 출전별 행을 만듭니다.
4. 실제 데이터는 데이터 구분을 '실제 출전 정보'로 저장. 추가 샘플을 만든 경우 수정하거나 삭제합니다.
5. 현장에서 대기·경기 중·완주 버튼 사용. '저장되었습니다'를 확인해야 저장 성공입니다.
6. 날짜는 ISO 날짜, 시간은 한국 시간(KST)으로 입력. 시간의 자동 상태 전환은 없습니다.

## 실제 운영 전에 받을 정보

- 대회명·장소, 2026년 및 KST 적용 확인. 해외 대회라면 시간 기준 확인.
- 출전 명단·종목·일정은 제공받았습니다(11/13: 13개, 11/14: 9개, 11/15: 5개). 웨이브/메모는 선택 사항입니다. 외부 파트너 이름은 필요하지 않습니다.
- 추가 관리자 계정의 ChatGPT 이메일, 선수 이름 공개 동의 여부.
- LINKX 로고/공식 색상(선택), 원하는 도메인(선택).

## 확인 범위와 한계

자동 검사: 익명 조회, 인증/권한/Origin 거부, 잘못된 날짜·시간, CRUD, DB 재조회, 오래된 버전 충돌, SSE 첫 데이터, 빈 일정 유지. 로컬 UI 검색/필터/반응형 확인. 실제 관리자 계정의 로그인과 다른 휴대폰까지의 전송은 사용자의 최초 로그인 후 운영 점검이 필요합니다. 기존 DB가 이미 초기화된 경우 자동으로 명단을 덮어쓰지 않습니다. 이번 업데이트는 아직 배포되지 않았습니다. 별도 선수 프로필 DB 없이 출전 단위로 관리합니다.

## 배포

`node build.mjs` 후 Sites source helper로 정확한 소스 상태를 push/package하고 저장된 버전을 공개 배포합니다. 산출물은 `dist/server/index.js`와 `.openai/hosting.json`, `drizzle/`입니다. 사이트 ID를 새로 만들지 말고 기존 ID를 재사용하세요. 환경값·계정 비밀정보는 소스와 배포 압축파일에 포함하지 않습니다.
